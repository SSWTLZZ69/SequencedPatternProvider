# 子供应器

子供应器负责把某一步需要的物品送进正前方的机器。带特殊纹理的一面是输出面；AE 线缆应连接其他面。

要让子供应器工作，需要同时完成三件事：接入主控所在的 AE 网络、连接到主控、设置与样板一致的路由标记。

## 连接到主控

1. 用 <ItemLink id="ae2:memory_card" /> **潜行右击主控**。
2. 松开潜行键，用同一张内存卡**普通右击子供应器**。
3. 打开主控界面，确认“已连接子供应器”数量已经增加。

潜行右击子供应器不是连接操作，而是保存子供应器设置。

## 设置加工类型

手持一个用来表示这条加工线路的物品，普通右击子供应器，即可把它设置为路由标记。编码终端中对应步骤的“路由标记”槽也必须放入相同物品。标记只用于选择子供应器，不会被发送进机器或消耗。

一个子供应器可以设置多种标记。例如，可以让多个使用相同机器的步骤共用一条加工线路，也可以用不同物品区分不同的加工线路。

## 让多个主控共享一个子供应器

一个子供应器可以连接到多个主控，适合单个主控的九个样板槽不够用的情况。所有关联主控必须和子供应器接入同一个 AE 网络。此时子供应器仍是一条共享产线，它的发送缓存、正面目标、阻挡检查和合成锁由所有关联主控共同使用。

空手右击可以打开界面。界面会显示它绑定的路由标记、AE 是否在线、正面是否有可用目标，以及暂存的物品和流体。“清空”按钮会删除全部路由标记。

## 复制设置

用内存卡潜行右击子供应器，可以保存它的路由标记、阻挡模式、锁定合成模式、输出方向和名称。再用这张卡普通右击另一个子供应器即可应用。暂存物品、流体和当前合成锁不会被复制。

## 同一种加工使用多个子供应器

可以把多个负责同一种加工的子供应器连接到同一个主控。主控会在它们之间轮流分配任务。如果某个子供应器离线、被阻挡、仍有物品等待送出，或者正面目标拒绝接收，主控会继续尝试下一个。只有全部同类型子供应器都不可用时，任务才会等待。

## 阻挡模式

左侧按钮遵循 AE2 样板供应器的阻挡模式。

- **关闭：**只要正面的目标愿意接收，子供应器就可以发送下一批。
- **开启：**只要正面目标中还留着该子供应器能够处理的任意已编码步骤所使用的物品或流体，子供应器就不会发送下一批。

阻挡模式会检查主控内全部样板中由这个子供应器负责的材料，而不只检查当前这一批。它只查看正面目标中能够被读取到的库存，不会等待半成品返回。

## 锁定合成

左侧第二个按钮与 AE2 样板供应器的“锁定合成”按钮相同。它和阻挡模式是两个互不替代的功能。

- **直到红石脉冲：** 每次发送一批后锁定，收到下一次完整的红石脉冲后解锁。
- **有信号时 / 无信号时锁定：** 根据当前红石信号动态阻止发送下一批。
- **直到产物返回：** 每次发送一批后锁定；该步骤预期的中间产物或最终产物进入 AE 网络后解锁。产物既可以从子供应器返回，也可以从网络中的其他入口返回。

切换锁定模式会清除当前锁定。在主控中中止全部任务，也会解除这些任务留下的“直到产物返回”锁定。

加工后的半成品不必从这个子供应器返回。它可以通过进口总线、接口或其他方式回到主控所在的 AE 网络。
