# 序列组装样板供应器

这个附属让 AE2 把一整条机械动力序列组装当成一个配方。玩家不需要再为每一步、每次循环分别制作处理样板。

需要三种设备：

- [样板编码终端](encoder.md)：制作序列组装样板。
- [主控供应器](master-provider.md)：保存样板并接收 AE 的合成订单。
- [子供应器](child-provider.md)：把每一步需要的物品送进机器。

## 快速搭建

1. 把主控和子供应器接入同一个有电、有频道的 AE 网络。让每个子供应器的正面朝向对应机器或输入容器。
2. 打开编码终端，在 JEI 的序列组装配方页点击 **+**，检查每一步的材料和路由标记，然后编码样板。
3. 对于样板中的每种路由标记，手持相同物品**普通右击**负责该加工的子供应器。
4. 手持 <ItemLink id="ae2:memory_card" /> **潜行右击主控**，记录这个主控。
5. 松开潜行键，用同一张内存卡依次**普通右击子供应器**。主控界面的“已连接子供应器”数量会随连接成功而增加。
6. 把样板放进主控，在 AE 终端下单最终产物。

连接子供应器时不要潜行右击子供应器。潜行右击子供应器的作用是复制它的设置，不是连接主控。

无法下单或任务停止时，请看[搭建与排错](workflow.md)。
