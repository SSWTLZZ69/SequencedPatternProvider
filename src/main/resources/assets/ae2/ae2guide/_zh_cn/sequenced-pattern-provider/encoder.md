# 样板编码终端

把终端装在 AE 线缆上，然后打开界面。

最简单的编码方法：

1. 在 JEI 打开一个机械动力序列组装配方。
2. 保持编码终端开启，点击 JEI 的 **+**。
3. 检查开始物品、最终产物、加工步骤和循环次数。
4. 放入 AE2 空白样板，点击编码箭头。

编码后会得到本模组的已编码序列组装样板，用来保存额外的步骤信息。手持它潜行右击，或点击终端的清除按钮，就能还原成 AE2 空白样板。

每一步有上下两个槽位：

- **材料槽：**这一额外消耗的物品或流体。没有额外材料时可以留空。
- **路由标记槽：**主控用这里的物品选择子供应器。这里可以放任意物品；标记只代表目标黑盒，不会作为材料发送。

编码完成后，要用每一步的路由标记物品普通右击负责该加工的子供应器。子供应器上的标记与样板中的标记相同时，主控才能把这一步交给它。

终端支持单次循环最多十步。电力、应力、热量等条件由机器产线提供；只有配方明确要求的物品或流体才需要放进材料槽。

## 概率产物

选择概率产物后，终端会自动把多次加工组成一个批次，并按配方概率折算 AE 计划中的产量。例如，80% 概率的精密构件会编码为 **5 次尝试 → 4 个精密构件**。其他产物和超出计划数量的目标产物会一起进入网络。

同一个批次可以交给多台负责相同加工的机器，完成顺序不会影响主控继续执行后续步骤。即使某次加工没有产生物品，主控也会继续处理批次中的其他工件。
