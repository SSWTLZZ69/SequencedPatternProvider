# 搭建与排错

## 连接主控与子供应器

连接分为“接入 AE 网络”和“用内存卡绑定”两部分，两者都必须完成：

1. 把主控与子供应器接入同一个有电、有频道的 AE 网络。子供应器的正面朝向机器，AE 线缆连接其他面。
2. 手持 <ItemLink id="ae2:memory_card" /> **潜行右击主控**，记录这个主控。
3. 松开潜行键，用同一张内存卡依次**普通右击子供应器**。
4. 打开主控界面。每成功连接一个子供应器，“已连接子供应器”数量都会增加。

如果数字没有增加，请确认对子供应器使用内存卡时没有按住潜行键。潜行右击子供应器会保存它的设置，不会连接主控。

同一张卡会继续保留主控信息，可以连续连接多个子供应器。对着空气潜行右击可以清除内存卡记录；主控界面的“清空连接”会移除这个主控的全部子供应器连接。

## AE 中看不到可合成的产物

依次检查：

- 编码后的样板是否已经放进主控。
- 主控和子供应器是否有电、有频道，主控界面的连接数量是否正确。
- 样板中的每一种路由标记是否至少有一个子供应器设置了相同标记。
- 主控的任务数量是否已经达到配置上限。

## 任务停在某一步

- 找到负责这一步加工类型的子供应器。
- 检查它的正面是否朝向正确的机器或输入容器。
- 检查机器的电力、应力、热量和剩余空间。
- 如果开启了阻挡模式，清理正面目标里残留的输入材料。
- 确认加工后的半成品已经回到主控所在的 AE 网络。

产线无法恢复时，可以打开主控并点击**中止全部**。已经进入机器的材料仍需手动回收。

## 复制子供应器设置

用内存卡潜行右击子供应器，可以保存它的路由标记、阻挡模式、锁定合成模式、输出方向和名称。再普通右击另一个子供应器即可应用。内存卡一次只保存一种内容；需要继续连接主控时，应再次潜行右击主控。

## 给设备命名

命名方式与 AE2 设备一致：用石英切割刀制作名称压印模板，再通过压印器给主控、子供应器或编码终端物品命名，最后放置。名称只用于辨认设备，不会代替内存卡连接或路由标记。
