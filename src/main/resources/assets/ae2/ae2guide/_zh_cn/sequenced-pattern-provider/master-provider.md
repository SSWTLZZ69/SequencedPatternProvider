# 主控供应器

主控是 AE2 规划合成时看到的设备。它需要一个频道，可以放九张序列组装样板。

## 连接子供应器

主控和子供应器接上 AE 线缆后，还需要用内存卡建立连接：

1. 手持 <ItemLink id="ae2:memory_card" /> **潜行右击主控**，记录这个主控。
2. 松开潜行键，用同一张内存卡**普通右击子供应器**。
3. 继续普通右击其他子供应器，可以把它们连接到同一个主控。
4. 打开主控界面，确认“已连接子供应器”数量已经增加。

这项连接不能代替 AE 线缆。主控和子供应器仍然都要接入同一个有电、有频道的 AE 网络。

连接时不要潜行右击子供应器。潜行右击子供应器会保存它的设置，用于复制到另一个子供应器。

样板中的每一种加工类型都必须有一个已连接、在线并负责该类型的子供应器。条件不齐时，AE 不会显示这个产物可以合成。

主控界面会显示：

- 已放入的样板。
- 已连接的子供应器数量。
- 正在运行的任务数和任务上限。
- **中止全部**：停止所有任务，并退回主控还没有送出的材料。

已经进入机器的物品无法通过“中止全部”取回。

机器加工完成后，把半成品送回主控所在的 AE 网络，主控就会继续下一步。半成品可以从子供应器返回，也可以通过进口总线、接口或其他网络入口返回。

当正在运行的任务达到上限时，新的订单会等待。这个上限由服务器配置决定。
